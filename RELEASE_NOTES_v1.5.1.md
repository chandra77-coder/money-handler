# MoneyMate v1.5.1 - Stability & Dark Mode Fix

This maintenance release focuses on fixing UI visibility issues and refining the logic for the new Work feature.

## What's Fixed?

### 🌙 Dark Mode Visibility
*   **Bright Numbers**: All account balances, transaction amounts, and work totals now use high-contrast bright colors in Dark Mode.
*   **Enhanced Contrast**: Refined the dark theme palette to ensure all text is easily readable against the deep ocean background.

### 💼 Work Feature Refinements
*   **Accurate Stats**: Earnings and job counts now correctly filter for "Work" types, ensuring that "Spend" records (business expenses) don't inflate your income stats.
*   **Smarter Analysis**: The Work Analysis section now only displays job categories that have active records, keeping your dashboard clean and relevant.
*   **Strict Validation**: Improved the entry form to ensure a payment method (Online/Cash) is selected when marking a job as "Paid".

## Other Changes
*   Updated versioning across the application to v1.5.1.
*   Cleaned up internal logic for better performance.
